# 聊天绘图接管与交付设计

本文拥有主聊天图位、原生生成接管、显示和取消边界。场景理解与计划见 [Scene Planner](./scene-planner-design.md)，后台执行与恢复见 [Image Job](./image-backend-batch-jobs.md)及 [Draw Run](./backend-draw-runs.md)。三家 Provider 各自拥有请求、编译与供应商结果。

## 所有权与身份

- [chat-image-session.js](../modules/draw/shared/chat-image-session.js)：生成期间的接管与图位任务身份。
- [chat-message-images.js](../modules/draw/shared/chat-message-images.js)：消息展示与订阅；DOM 被重绘后按现有任务事实恢复。
- [chat-image-placement.js](../modules/draw/shared/chat-image-placement.js)：正文替换、删除及位置映射。

任务身份依赖聊天消息对象、分支、生成范围和标签位置，不依赖 DOM、可见性或不会变化的楼层下标。接管与显示观察仅在运行期存在，不另建持久化缓存、锁或任务副本。

## 原生生成与保存

接管完成边界先恢复已提交图位，再允许 DICE 同楼处理，最后解析剩余标签。多次续写准备交错只能恢复已提交图位；其他图位删除或前楼移动后重新定位，真正编辑或目标变化使过期接管失效。

正常原生回复的交付顺序为：图片输入落图库 → 同步替换正文及当前 swipe → 交还宿主原生保存。不等待供应商完成，也不额外保存/读回整聊天。历史标签、编辑保存与重挂载只提供展示或手动入口，不重新自动购买图片。后台提交与接回需要的确认保存另遵守后台协议，不混入普通原生生成。

正文中的图位是排版事实，DOM 是可重建视图。宿主重绘后按原任务恢复卡片，不重买；写前重新核对消息、分支和存活图位。迟到结果可留图库，但不能写到另一消息或复活用户已删除的图位。删除标记归既有任务记录，随其结算/清理释放。

## 任务状态与取消

Provider 任务登记统一服务胶囊、自动配图、原生标签及重绘批次。批次独立取消，按聊天/消息/当前分支聚合；已结算兄弟批次保留到聚合结束。胶囊挂载直接读取当前汇总，不依赖此前通知是否被接到；后台 handoff 不冒充全部完成，排队项不显示为正在生成。

取消先捕获目标，逐项保存已有取消意图并发送取消请求。单项已结算不阻断其他项；活跃执行者读取取消意图后推进自身信号。停止文字生成不等于取消早前已提交的图片批；图片取消从对应绘图入口发起。

提交前取消、明确拒绝、已知成功、提交后未知必须区分。已解码成功不被后续取消抹掉；未知请求不自动重发，保留再计费风险，不让胶囊永久显示确认中。

NovelAI 电子书、Tavern 与普通文本入口不依赖聊天楼层，仍遵守各调用方取消信号与图库归属。共享绘图 facade、宿主内容挂载和 DICE 检定规则各由原功能拥有。

## 检查与限制

共享测试位于 `modules/draw/shared/tests/`，三家 Provider 测试位于各自 `tests/`。浏览器夹具中的 `provider-browser-host.mjs`与 `provider-browser-*.mjs`使用真实宿主生成/事件/保存链路和隔离供应商，不能用于真实用户聊天或计费验收。

重点保护：续写/swipe/重生成交错、无 DOM 与宿主重绘、DICE 同楼位置映射、切聊/切分支、输入落库失败、聊天保存失败、逐项取消、未知结果和显式删除。隔离测试证明交付链路，不证明真实供应商图片质量、系统冻结后台页、Tauri/移动 WebView 或正式宿主可部署性；后两者还要求对应构建与运行检查。
