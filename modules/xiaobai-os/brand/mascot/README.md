# 小白形象

**母版是会动的 3D 角色，不是静态大图。** `design.ts` 固定组成、比例、表情和配色；`model.ts` 用这些数据生成实体；`performance.ts` 固定站立、抱物跑动的节奏和呆呆的步态。搬家场景只提供角色所在的位置、目的地和要搬的物件；不要在游戏或其他 APP 中复制一套模型或动画。改小白的造型或动作，先改本目录，再回游戏里看真实运动画面。

`svg.ts` 是 3D 模型的简化正面投影；`portrait.svg`、`mark.svg` 是 `build.mjs` 自动生成的静态辅助图，用在容不下 WebGL 的小尺寸位置，不定义角色长相。早先 `output/playwright/xiaobai-moving-mascot-large.png` 是手画的参考图，也不是母版。桌面小标记不覆盖用户角色壁纸。

不变的识别点是奶白椭圆身体、两只直立圆耳、两颗深蓝灰小眼、浅粉腮红和蓝灰小脚。面部不加鼻子或嘴；跑动时先短暂停顿，再身体轻轻上下颠、略微侧身抱物件。纸箱是搬家场景的道具，不是身体的一部分。其他应用只有确有角色参与的场景才引用该模型或它的静态投影。

来源：当前设计从本仓库搬家游戏的程序化角色整理而来（最初加入于 `d23ad836`，2026-09-27），不含下载的兔子图片或外部模型。2026-09-28 使用者目视检索未找到相同形象，**这不是版权或商标清权结论**；对外独占或注册前另做相似形象与商标检索并保存检索证据。
