# 普通小白 OS「语伴」：施工方案

## 1. 状态、目标与首版范围

记录日期：2026-09-06。主人已确定产品名「语伴」，完整名「小白语伴」，内部 ID `learning`。产品事实来源为 [语伴产品设计](./language-learning-app-target-design.md)。**前四批已实现并注册正式 APP，第五批真实宿主／模型／音频验收尚未完成。** 当前验证使用隔离文件、固定 Provider 与媒体边界替身，未请求付费服务、未提交或推送；分项证据与限制见 §13。

语伴是由熟悉的角色担任老师的语言学习应用。真实教材、可操作练习、具体反馈和复习是主体；角色与共同记忆提供陪伴。它不推进故事，不写 `/sendas`，不增加 D1/D3/D4 注入，不参加接受轮维护，不把教学质量等同于角色扮演质量。

### 1.1 完成的最小闭环

选择老师和目标语言 → 确认学习目标与自评 → 准备有出处的材料及短单元、展示完成奖励 → 阅读/听取、标记、作答、获得反馈 → 老师依据实际学习发起结课 → 确认保存学习成果 → 在所属聊天自动结算 → 继续追问或下次换情境复习。

- 首版包含：用户级多语言档案、老师选择、Tavily 检索与正文提取、原生练习组件、提问与提示、证据式学习记录、恢复与删除、聊天级奖励、桌面图标与完整 UI。
- 声音不是占位：首版包含 TTS 示范、讲解朗读、合成材料的听后理解/听写，以及独立播放、暂停、重听、进度和慢放。
- 录音/转写/音频评价属于后续独立接入关口，见 §10.3。课程和作答边界从首版就正确，不预建没有服务消费者的空音频字段，不宣称首版已能听懂或评判用户发音。
- 不做多 Agent 教学流水线、长期固定课表、实时语音通话、全网爬虫、考试真题平台、排行榜、断签惩罚、广告式催学或自动重试。

### 1.2 施工默认值

以下是本方案选定的实现起点，不是已验证的教学结论；集中放在 Learning 自有常量里。调整后只影响新单元/新请求，不能改掉已发布题目的要求或已保存奖励。

| 项目 | 默认与上限 |
| --- | --- |
| 首次了解 | 目标语言、自评（可“不知道”）、目标；日期和等级名可空。最多再用一个短练习了解情况，不强制长测级 |
| 多语言 | 常用语言快捷入口 + 合法语言标签；等级/考试目标保存原体系，不换算一个全球总等级。首先真实验收英语、日语，不宣称全部语言教学效果相同 |
| 当前课程 | 每语言保留 1 个当前单元，含结课后供追问的课件；普通单元建议 4 题、少练一点 2 题，最多 8 题。题数是备课参考，不是结课门槛；老师依据目标与实际学习判断 |
| 一次选材 | 1 个小目标、1 份主材料；单元最多 3 份材料。每份正文上限 6,000 码点，长来源用明确节选，不截断到无法理解 |
| 一次联网 | 搜索默认 5 条、上限沿用现有 8 条；提取最多 2 个候选网址/调用，每次教学动作最多 2 次搜索、4 个提取网址。用尽后说明情况，不无界换词搜 |
| 作答与反馈 | 单次文字作答 4,000 码点；题干 1,200；单题解释 2,000；名称/目标短文分别 80/800。收藏讲解每单元最多 12 条 |
| 学习项 | 单个可练的词/表达/规则/策略；一次评估最多增改 5 项，每项最多保留 3 份代表性证据；不会将全文自动切成词库 |
| 复习 | 初次独立成功后 1 天、再次隔时换题成功后 3 天；有三份异日异情境成功时，按保留证据的实际间隔取 7/14/30 天封顶。答错或辅助后完成回到 1 天，晚来不扣级。状态与日期从证据重算，不存隐藏成功计数；这是排课启发式，不是官方掌握认证 |
| 奖励 | 短练 20、常规 40、深练 60 小白币，发布单元时程序确定并展示金额，一单元一次；分档依据见 §9.1。老师通过工具结课，保存确认后自动结算；对错/提示/声音设备不减奖，复习同规则，无日上限、连签或罚款 |
| 播放 | 默认点击才播放；速率 0.75/1/1.25，使用本地播放器，不反复合成；示范按句段合成，每段最多 500 码点 |
| 请求 | 每次只运行一个所属教学动作；工具循环最多 8 轮。网页请求 30 秒超时、模型动作沿用 Provider 超时能力并保留取消，不后台无限续跑 |

奖励使用已确认的 20/40/60 小白币三档固定价格，不建立防刷排行榜系统。

## 2. 开工检查：终态结构与唯一来源

| 检查项 | 决定 |
| --- | --- |
| 功能所有者 | `domains/learning` 拥有学习事实/判定；`apps/learning` 拥有存储、素材、教学请求、工具、声音与 UI |
| 用户级唯一来源 | 当前宿主账号的 `LittleWhiteBox_Learning.json`。学习档案、单元、证据与完成事实不进角色卡或聊天分区 |
| 聊天级唯一来源 | `learning` 分区仅保留当前聊天选择的老师 `{name,note}`，可空；资金事实只在 Economy |
| 临时态 | 请求/候选、展开/选区/滚动、未提交输入、当次问答尾部、音频对象 URL/播放器状态/设备句柄；不持久化运行队列或模型思考 |
| 外部依赖 | 宿主用户文件接口、PromptContext/Story Summary、共享 Agent 配置与 Provider、Tavily、TTS、现有 Economy 与 Kernel |
| 注册入口 | 自有 module/descriptor/production-module，Host/Shell catalog、Shell 懒加载和 production composition；不注册维护 participant |
| 删除路径 | 停所属运行 → 清用户文件和本聊天老师偏好 → 移除注册/目录；保留主聊天、公共 API 设置、他域数据和既有奖励流水 |
| 兼容对象 | SillyTavern 文件/身份/事件、浏览器与 WebView、供应商协议、当前导出格式。没有自己的历史版本，不写旧 schema 兼容壳 |
| 最少测试 | 领域输入输出、真实文件边界的集成、工具→保存→重开、奖励断点、跨卡资料隔离、关键 UI 与真实教学/媒体验收 |

聊天中保存老师选择有独立产品用途：回到同一聊天不必重新选老师；它不是学习资产，也不是为借事务而造的空分区。与此同时，它可使用当前分区事务合法调用 Economy，避免新增无所属分区的通用写入机制。

module 的 `clearData` 只清当前聊天的老师偏好；删除聊天、清理 sidecar、关闭 OS 都不删除用户文件。只有语伴内明确的「删除语言/清空学习数据」或功能卸载清理才操作用户资产。聊天文件/钱包故障可阻止选老师、领奖，但不得让已有用户学习记录一起不可读。

```text
modules/xiaobai-os/
├─ domains/learning/             档案、教材/题目、尝试/评估、学习项、完成资格与校验
└─ apps/learning/
   ├─ module.ts / partition.ts   用户仓库注入；聊天分区仅老师偏好
   ├─ application/              单元流程、复习、提交/复核/删除、奖励协调
   ├─ storage/                  用户文件封装、保存确认与当前格式导出
   ├─ agent/                    教学请求、工具声明/执行、资料投影和 Prompt
   ├─ materials/                检索→提取→节选/出处验证
   ├─ media/                    课程播放与 TTS 适配；录音上线后归此
   ├─ host/                     上下文、协议、Controller 与取消生命周期
   └─ ui/                       书桌、课堂、原生题型、学习记录与本地图标
```

这是一棵职责树，不是要先生成几十个空文件。文件随实现职责产生；不建全 OS 教育框架、用户数据库平台、通用题型插件市场。

## 4. 持久数据：一份用户文件，分开的事实

### 4.1 终态模型与当前落地范围

用户文件外壳只含 `schemaVersion`、`revision`、`commitId` 与学习正文。版本只认本次格式；commitId 标识这次已发出的完整替换，用于核实，不是课程或奖励 ID。

正文以语言档案组织，包含当前单元、学习项/代表性证据、完成凭据和必要偏好。下面是语义实体，不要求拆成多文件或表：

当前用户文件为 `{schemaVersion, revision, commitId, data: {profiles}}`；每份语言档案包含目标／自评、当前 `unit`、`items` 与 `completions`，分别由课程接续、复习／复核、完成资格读取。老师选择仍在独立聊天分区，媒体偏好随第四批实际消费者落地。未发布的第一批草稿格式直接替换，不引入兼容分支或不透明 JSON 字段。

| 实体 | 必需事实与约束 |
| --- | --- |
| LanguageProfile | 规范语言标签、讲解语言、用户目标/考试体系/自评、媒体偏好。目标与实际表现分开；未测的技能没有推测等级 |
| Unit | 稳定 unitId、目标、材料/练习安排、已提交尝试与当前进度、来源范围、奖励归属 osId、发布时确定的奖励档位与金额。打开页面不新建单元，模型不能改已发布金额 |
| Material | 稳定 ID、语言、实际保存的文本/段落、出处与取得时间、原文节选/教学改写/自编、资料范围；声音在可用时有确定合成文本和音色信息 |
| Exercise | 稳定 ID、目标技能、材料引用、题干、回答形式、评估方式/答案规则、可用提示和必要引用。训练技能不从输入控件推断 |
| Attempt | 稳定 ID、exerciseId、真实原答、提交时间、实际帮助条件。Host 写入；模型不能创建用户尝试或改其原答 |
| Assessment | 对 attemptId 的判定、理解/表达分别反馈、改进建议、相关学习项与证据引用。复核修正这份结论，不复制互相矛盾的历史版本 |
| LearningItem | 可再次练习的表达/知识点/策略、目标技能、代表证据、独立程度、复习日期；待加强/待复习/已能独立使用只是视图 |
| Completion | unitId、真实完成时刻、给用户的结课小结、固定奖励意图与可选到账回执。由老师结课通过校验后创建，不是后台作业，不记录请求阶段；见 §9 |

材料、题目、尝试使用 APP 分配的稳定 ID。允许模型在一次调用内用局部引用连接新材料与题目，由工具结果返回实际 ID；不允许模型自行覆盖已提交题目的 ID/内容。已呈现的材料不可原地换成另一篇；新材料、新题有新 ID。

### 4.2 保存依据与删除路径

- 档案是用户长期意愿；单元/原答用于中断后接续；证据用于复核和复习；已发布奖励约定用于重开后保持同一承诺，完成凭据用于展示收获与恢复领奖。这些由 Learning 持有，删除与保存失败沿用本节规则，不另外存过程状态。
- 老师结课后仍保留当前单元供追问和重开查看，不立即销毁课件；用户明确开始下一单元时，将有价值的题目/原答/反馈收为代表证据，保留小型完成凭据，释放未被引用的材料/提示。每项最多 3 份证据优先保留最近两份不同情境的独立表现和最新纠错/辅助表现；不足时保留已有记录。不裁掉支撑当前“独立使用”判断的第二份证据，再靠无依据计数续存结论。
- 删除学习项同时删除其独占证据、讲解和推导标签；仍被别项/当前单元引用的材料不误删。用户可删除单个语言或清空全部学习数据，必须明确未领取奖励也将放弃；既有到账流水不撤销。
- 放弃未完单元删除其继续所需资料；已确认加入长期记录的学习项不跟着消失。删除整次作答时同时移除依赖它的评估，重算相关学习项，不伪装为一次答对。
- 支持当前学习数据 JSON 导出，导出不含密钥、候选、设备对象。首版不引入旧格式导入器或任意文件恢复向导。
- 总文件写入容量先设 8 MiB UTF-8，超出时保留旧版本并引导导出/清理；不自动删除已有学习项。不把这个写入容量或 Prompt 长度预算当成已保存档案是否合法的条件。
- 完成凭据不是第二本钱包：只保存这次完成和对应奖励的身份/回执，不保存汇总余额；清空学习数据不会使账本反向生成一批“待领取”。

### 4.3 用户文件的保存/未确认/冲突

1. 打开只强读、解析；404 是空档案，读失败/坏 JSON 是错误，不得初始化覆盖。
2. 仓库内串行写入，写前强读 revision/commitId，基于最新已确认事实执行命令。候选和原版本仅在运行内保留。
3. 上传前冻结整份候选，检查运行 guard；成功读回同一 commitId 和内容后再发布。上传异常也先独立 no-store 读回，网络断开不等于未保存。
4. 未确认时保留原已确认视图、冻结依赖该写入的修改，入口叫「核实保存」；不重新出题/批改。仍见旧版本不足以证明在途请求不会晚到，不能立刻新造候选覆盖。
5. 读回另一版本显示冲突，让用户明确采用服务器版本；不自动合并目标、原答或奖励。同一候选的可重发仅在没有未结束上传且版本仍匹配时发生。
6. 页面真正重载后以内存外的服务器事实为准：有已存原答即可手动续评；有完成凭据即可核奖。未保存的模型输出不承诺复原，不为此持久化请求队列。

宿主接口没有服务端 CAS。首版支持同一账号单个活跃写入会话：进程内串行；具备 Web Locks 的同源浏览器可在读改写期间互斥，不能把它宣传成跨设备锁。没有 Web Locks 的 LAN HTTP/WebView 仍可单窗口学习，但不承诺并行标签写入安全。识别到版本冲突即停止，**版本号和读回无法消除所有跨设备同时写的竞态**。如将来要求真正多设备并发，需另立宿主条件写能力，不在这里堆锁文件、心跳或永久租约。

仓库实例须由 Host 会话持有，关闭/重开 OS 不丢失内存中的未确认写入。Web Locks 只保护本次文件操作，不证明其他窗口没有尚未落盘的超时请求；整页重载也无法恢复已丢失的运行态。未确认期间保持单个写入会话并先核实，不宣称支持在旧上传状态未知时换窗口继续写。

浏览器 fetch 中止本身不是服务端已结束的证据；仍无法确定上传是否结束时，「核实保存」只读，不自动重传或解除写入冻结。真实宿主探针必须覆盖晚到写入，不能仅用同步内存 mock 声称这条风险已解决。

## 5. 老师、跨卡与学习上下文

### 5.1 三种身份不得混用

- 当前宿主账号决定学习文件所在用户空间，不使用 name1/name2 做账号键。
- 运行时 chatIdentity + APP 激活代次 + 语言/老师选择决定异步结果是否仍属于本次课堂。
- osId 是当前故事存储身份，记录单元原始奖励归属和敏感资料范围。课程开始前老师偏好保存确认，因而 osId 已实际存在；不由显示名/聊天文件名临时拼出永久身份。

老师候选来自已知人物，排除玩家和其已知别名；不把卡标题 name2 当老师，也不把 name1 生成人物。允许用户按姓名/必要说明补老师，保存的是选择，不另建通用人物档案。候选选择逻辑可从 Messages 提取为两个消费者共享的窄 helper，学习不依赖联系人分区。

### 5.2 能随人走的进度与不能串卡的故事

- 语言目标、真实学习证据与掌握状况不因切卡/换老师/分支清零；新老师不必重新测试。
- 卡片/世界书/近期剧情/共同记忆每次从当前聊天读取，绝不从旧课重放旧卡全文。普通学习不自动读取 Messages 私聊、Fourth Wall 对话、世界新闻、任务或地图状态。
- 材料/证据带由 Host 决定的范围：公共教材或无故事背景生成的内容可跨卡；含故事/角色私密资料的材料、题目、讲解与用户答案按 osId 隔离，不能仅因模型标为“通用”就降为公共。
- 公共课程也可能收到故事范围内的答案或老师讲解，因此 Attempt、Assessment 各自保存资料范围；不因课程公开就公开所有派生问答。
- 全局进度可显示已经练过哪些技能；跨卡的具体复习材料只取可传递证据。仅有旧卡私密证据的知识点，传递结构化技能结论而非那道题的原文；需要新练习时用公开/自编新情境，不让新老师读旧故事。
- 用户自己可查看有来源标识的旧记录；浏览并不授权发给当前老师。私密原题的「问老师/再练」只在原 osId 开放，别处说明需回原聊天或另开一题。
- 公共材料单元可在新聊天继续，新老师使用当前背景；奖励仍属原 osId，结束时明确。私密材料单元不可带到新卡续问，保留原课并提供返回原聊或明确放弃后新开课。
- 复制/分支获得新 osId，不复制学习文件或产生完成资格；老师偏好可以随聊天复制。分支视为新的故事范围，不自动获得父线课堂的敏感问答。

跨范围的“结构化技能结论”仅指程序定义的技能/独立程度/复习条件等白名单字段，不夹带模型自由写的旧卡摘要、题目标题、人物姓名或私密例句。范围从本次实际输入与所引用资料传播，模型无权自行去掉；公共课堂内容一旦引用故事资料，派生内容也归对应故事范围。

### 5.3 同一个角色老师，按需调用工具

所有教学动作由同一位老师完成，均保留当前老师与共同经历的必要资料。搜索是老师手边的普通工具，检索词由老师生成；不因联网另拆上下文、不增加选材 Agent 或搜索审批流程。在这个共同底座上，按动作补充学习资料：

| 动作 | 放入的资料 |
| --- | --- |
| 选材、出题/复习 | 当前语言目标、能力证据、必要教材；老师自主搜索、读正文并组织课程 |
| 评估/复核 | 完整本题、必要材料、已保存原答与已有反馈；原答不可因预算静默截断 |
| 老师讲解/自由提问 | 当前问题及必要题目、材料；不为讲解另换一个去掉角色记忆的上下文 |
| 老师收课 | 当前单元目标/安排、真实尝试与反馈、已确定奖励；结课只引用可读取的学习事实 |
| 修改目标 | 用户本次明确表达、当前目标；不能按角色卡能力或一次错题改掉期望目标 |

固定答案只对模型出题时提供的答案键，不理解语言；多解和开放表达由老师评估。普通客观题提交不额外生成对白，安排的末题后接一次老师收课判断。

资料范围仍沿用 §5.2：本实现的老师请求携带故事资料，自由生成的课件、反馈与讲解属于当前 osId，不由模型自行声明为公共。用户级语言目标和结构化学习进度照常跨卡；已有公共教材的数据类型仍可读取。不能把“公开网站文章”误当成“这整堂角色课堂都不含故事资料”。

每次请求只注入本语言档案、当前目标/题目/已提交原答、相关学习项、必要材料。最近问答最多 8 轮、合计 8,000 码点，属于当前课堂运行内；更早闲聊不自动总结成水平资产。收藏讲解有材料/题目锚点并在同一资料范围读取，重开靠已确认单元/证据继续，不靠无限师生聊天日志。

单次动态资料总预算 32,000 码点：目标/题目/当前原答优先；材料按完整段落取；相关学习项最多 12 个；老师/故事最多 8,000；最后放最近问答。预算在消费方降级并列明省略及补读入口，不参与存档 parse。实际 Provider 上下文不足时停止并说明/减少可选资料，不静默裁掉作答或题意。

## 6. 课程、原生题型与教学证据

### 6.1 题目不等于界面代码

Exercise 分开保存：训练技能、材料引用、呈现内容、回答形式、判定规则。首版只有有限的原生回答控件，不让模型生成 HTML/CSS/SVG 或任意页面配置。

| 回答控件 | 具体契约 | 判定 |
| --- | --- | --- |
| 选择 | 2–6 个稳定 optionId，可单/多选；选中可改，提交才记尝试 | 按已发布正确 ID 集合本地判断；异议可请老师复核 |
| 匹配/排序 | 最多 8 项；匹配用成对 ID，排序用 ID 序列；同时提供点选/上下移，不要求拖拽 | 显式唯一关系才本地判断；有合理多解就使用语义评估 |
| 原文依据 | 选保存材料的句/段 ID，可多选；手机不要求精确字符拖动 | 有明确依据范围可本地；需解释论证时语义评估 |
| 填空 | 最多 6 空，每空独立输入；规则保存可接受形式与是否区分大小写/标点 | 精确可判部分本地，不擅自做英文 stemming 或日文切词；其他有效表达交老师判断 |
| 自由文字 | 改写、补句、回答、复述、观点、听写都可用；题目说明目标与限制 | 语义评估分理解和表达；长度、华丽词汇不是得分规则 |

听力是声音材料 + 上述选择/文字控件，不是第六种资产。跟读无录音时只显示自练，不算已验证口语能力。答案与文稿不得默认露在听力 UI、替代文字、题目标题或其他提示气泡中；这保护正常学习流程，不声称浏览器客户端答案具有考试防作弊保密性。

本地客观题在课件保存前已有明确答案/简短解释，提交后无需模型即可回应；开放题或争议调用评估。未解决/有歧义的题不能算用户错误，也不能以默默换答案方式修复。

### 6.2 阅读标记与帮助条件

材料保存后按段/句建立稳定锚点，显示文本保持原样。精确选区记录 materialId、段 ID、UTF-16 起止及原文引用；偏移来自浏览器选区，不能要求模型数坐标，也不能与码点长度混算。存入长期证据时验证引用仍匹配。

选中、取消选择和「标记不懂」不请求模型；不懂是学习需求，不等于错误。问老师/索取提示才发请求，只带选段和必要上下句。手机和键盘有「选句提问」替代入口，不靠长按一个隐藏菜单。

Host 记录看文稿、看答案、用提示、重听和慢放等实际帮助；同一材料已读过不能刷新页面后当作首次盲听。文稿/答案等会影响独立性的揭示，先保存已揭示事实再展示；失败提示重试，不留下无法恢复的“看过但无记录”。重听次数等普通使用条件随作答一起保存，不逐点击建事件表。

与当前题有关的老师讲解/翻译也属于帮助，确认显示后才计入条件；模型请求失败不算用过帮助。读过公开材料后，不能通过在另一单元重新引用同一材料 ID 绕过“已看文稿”；素材曝光事实随其仍可复用的记录保留，不另外建立全网站阅读追踪库。

Attempt 保存提交时条件快照。`help.feedback` 表示提交前已有当前可读的同题反馈；它由已保存作答与反馈推导，不由模型填写。此事实随原答／保留证据存续，换课后仍可判断独立性；删除对应原答／证据时一起释放，保存失败不发布候选，不另存反馈曝光日志。语音服务失败、用户跳过、只标记不懂都不生成答错记录；先辅助再答对不是首次独立掌握。显示等待评估时保留原答，评估失败只重试该 attemptId。

### 6.3 学习项与复习

学习项可由评估提出，Host 校验 evidenceId 确实属于当前尝试、材料/原文匹配、技能与作答载体一致，再原子保存评估和学习项修改。模型不能造“已经练了五次”的历史。

「已能独立使用」至少需要两个不同情境、不同日的无答案/提示依赖成功，其中有符合目标技能的主动运用证据；一次选择题答对只能记录识别成功。没有真实音频依据，就没有发音/口头流利度的掌握结论。天数用于复习安排，不把没来学习当遗忘事实。

每项证据有限，复核时更新对应结论并重算此项状态/下次日期；有争议的评估先标为待复核，不继续作为确定错误或掌握依据。删除依赖证据要重算，不把旧判断藏进另一段不可删摘要。

开始新单元时按当前目标选少量到期项，再加一个新目标；不是每日随机抓文章，也不把到期项全变成欠账。重试同题服务理解，不推进“隔时迁移成功”的阶梯。

## 7. Agent 与 Tool 契约

本节是开发者契约，不是直接注入模型的提示词。正式 Prompt/description 施工时必须使用 `writing-model-prompts` 技能，读原型、查实现、按事实分层；本轮不编写尚无实现支撑的模型例文。

### 7.1 一处定义一种责任

- Learning 请求前言：老师与现实学习者的关系、资料角色、通用工具返回和本次动作收尾，只定义一次。
- `agent/prompt.ts`：目标/自评/表现的区分、如何选训练、怎样反馈和复习、什么证据支持什么判断。不是题型枚举和错误代码清单。
- `agent/tool-contract.ts`：具体工具做什么/何时用、返回形状；字段语义、默认/上限、省略/null 意义由 schema 表达，复用领域常量。
- `agent/data-projection.ts`：与 Read 共用资料形状；实际存在的 IDs 直接给，不强迫模型先花一轮读已有资料。缺页/裁减明确，答案侧数据不误发给 UI。
- 持久资料只存学习事实，不存身份、模板、提示词、系统例子或运行引导。

用语保持课堂视角；不复制维护 Agent 的“处理所有领域”收尾或 ebook 的“导入书籍/LS”说明。默认英文编写内部决策/工具说明；用户可见教学语言由讲解语言和目标语言决定，老师称呼与语气不强行英文化。

### 7.2 最小工具集

| 工具 | 输入/返回与所有权 |
| --- | --- |
| LearningRead | 读档案、当前单元、材料段、尝试/评估、学习项；分页默认 20 上限 50。返回当前请求允许范围内的原始事实、游标和是否省略；越过聊天资料范围拒绝 |
| LearningProfileEdit | 依据本次用户表述增改目标/自评/偏好；省略保留、可空字段用 null 清除。只在用户正进行档案修改时开放；不以表现擅自改目标 |
| LearningSearch | 接收教学主题/目标语言的查询与结果数；返回搜索候选 ID、URL、标题、摘要。复用 search 传输，不将摘要变成材料正文 |
| LearningExtract | 接收本次搜索候选 ID，最多 2 个；Host 取已知网址。返回 sourceId、实际正文分段、出处、成功/失败项及裁减信息。offset 默认 0，nextOffset 补读已提取正文，不重发网络请求；长段返回段号/码点偏移/是否读完。无任意本地 URL/内网代理能力 |
| LearningLessonEdit | 设置新单元目标、实际节选或明确的自编/改写、增改尚未展示题目；准备新课时选择奖励档位，金额由程序映射并在发布时固定。整批校验引用和题型；已展示/已有尝试的题不可改，返回实际 IDs、changed/unchanged/errors |
| LearningAssess | 以已保存 attemptId 提交结论、解释及有依据的学习项增改；评估与相关项同批校验，错误整批不应用。复核替换对应结论而保留原答 |
| LearningComplete | 引用当前 unitId、真实 attemptIds 及对应反馈，提交面向用户的结课小结；程序校验引用与评估后暂存完成事实，不接收金额/收款方，不直接记账。同一单元已完成时返回既有结果，不新增奖励 |

不提供模型发送用户答案、删除资产、任意发奖、扣币、写主剧情、任意读文件或写代码的工具。老师拥有教学结课权，应用服务在确认完成后按既定金额结算；删除、失败后领取/核实由明确 UI 动作进入。角色提问的普通解释可作为最终文字；用户选择收藏时才作为有限讲解保存。

Edit/Assess/Complete 统一返回 `{ok,changed,ids,errors}`；`ok:true,changed:false` 是成功不需重试；错误带公开字段路径与可修正原因。每次请求候选只在内存，整批错误不保留其中“看似成功”的项。失败调用要修正或以该工具的 `discard:true` 单独撤掉失败意图；撤回不取消以前成功暂存的修改。Assess 按 attemptId 跟踪错误，无关作答的成功不能洗掉先前失败。

已本地核对的题无需再生成一份评估：老师收课时可以调用 LearningAssess，仅发送 attemptId 和学习项，把既有反馈收为证据，保持原判断不变。已归档的代表证据可经显式复核替换反馈；关联学习项一起重算，不新造用户作答。

### 7.3 一次教学动作的提交

准备材料/出题/评估/结课的工具变更先暂存；最终正常结束、该动作相关错误解决、guard 仍有效后一次保存。LearningComplete 可引用同次动作中已通过校验的评估，但评估与完成事实必须同批保存确认；保存前不结算。网络中断、空回应、轮数耗尽不发布半堂课，不把工具返回成功当作已存档或已到账。

提交作答是不同边界：Host 先确认原答保存，再请求评估。评估中断不丢原答，下一次使用同一 attemptId，不重新搜文章、重建题目或重收答案。已经确认的评估只能读取/显式复核，普通重试不能再次覆盖。

需要语义评估时，老师可在同一教学动作内评估并收课。纯本地客观题仍立即给核对结果；用户提交当前安排的最后一题且核对保存成功后，接一次老师收课判断，不每题额外请求角色对白。到达最后一题只是调用时机，不是完成判据；老师在其他教学互动中已有充分依据也可提前收课。失败显示「重试收课」，只读取既有作答和评估；重开、看反馈不自动重发请求。

工具循环必须正确处理 Gateway 的 sessionToolLoop 与普通工具消息两种续跑；现有协议辅助函数继续用，不复制供应商适配。初始化时角色资料、学习资料、用户动作分层；HTTP 错误正文/Key 不进 UI 或持久记录。案例用真实工具输入执行，不做纯 Prompt 字符串快照测试。

## 8. Tavily 到教材：完整来源链

路径固定为：搜索摘要 → 选择已返回网址 → Extract 实际正文 → 选择连续段落/句子 → 保存教材 → 基于该教材出题。搜索结果临时，不保存所有候选或全网页镜像。

- Extract 首版使用同一共享 Key/Base URL、POST `/extract`、`urls`、`extract_depth:basic`、`format:text`、关闭图片；不传 query，避免实际得到重排片段却声称完整文章。实际鉴权、CORS/代理路径在首关以官方协议/测试响应和真实服务分别验证。
- 原始响应可能含导航、付费提示或空正文；没有足够可读段落就返回材料不足。HTTP 200 内 `failed_results` 仍是对应网址失败，不视为成功教材。
- sourceId 由 Host 为实际收到的正文分配。原文节选以 sourceId + 连续段落/范围选取，程序从原文取文本；模型不能提供一段自行改写的字符串再标原文。
- 改写/自编有独立标识；改写关联实际原文来源，但显示“教学改写”，不挂 BBC 名义冒充媒体原句。所有题只能依赖已提供给学生的必要材料。
- 原始响应先做网络大小限制（2 MiB），给模型的候选正文每来源最多 20,000 码点、按完整段落截取并标明；材料限长与存档字段校验独立。截取不到正文就换源，不靠臆造补齐。
- 网址仅限本次搜索返回的公开 HTTP(S)，拒绝带用户凭据、localhost/私网 IP/本地 scheme；不另开通用 fetch 代理。链接显示与点击使用安全 URL、`noopener noreferrer`，正文按纯文本处理。
- 搜索与正文读取由老师在同一工具循环内按需调用，复用 ebook 使用的共享 Tavily 搜索传输；不由程序审核或重写老师的检索词。
- 缺 Key 就提供 API 设置入口；不可访问/限流就保留旧课并提供重试、换来源或用户明确选择自编练习。查看已保存材料不重搜，打开链接是用户自己的浏览行为。
- 不承诺任意 BBC 页面可抓取，不绕付费墙，不默认转载全文；保存实际使用的必要节选和出处。官方考试要求优先原机构，练习题标练习而非真题。

新增 Extract 适配先归 `apps/learning/materials`，目前只有一个真实消费者，不为它扩成 Agent Core 通用网页平台；复用已有 Key 规范和搜索传输即可。

## 9. 完成与奖励：学习成功不被发币失败撤销

### 9.1 开课时确定奖励

奖励按学习量与相对本人水平的挑战分为短练、常规、深练：短练围绕一个小目标做少量练习；常规完成适合本人的理解、运用训练；深练是更充分的综合练习或进阶挑战。不是语言等级越高、文章越长、控件越复杂就奖励越高；复习可属于任一档。

老师备课时按内容选档，程序从固定表映射金额：`short`（短练）20、`regular`（常规）40、`deep`（深练）60 小白币，随 Unit 确认保存并在开课时展示。发布后不随配置调整、答错、提示、媒体设备、老师口吻或结课时表现变价，不按耗时、消息数、点击数或正确率算钱。

### 9.2 老师结课，程序结算

**老师依据实际学习发起结课，不以“至少两道题 + 用户点击结束”为条件。** 开课明确目标和练习安排，老师根据真实尝试、反馈及必要的修正判断本次目标是否已得到足够练习。一道有实质内容的练习也可完成小单元，不为凑数加题；“练过并理解了本次反馈”不等于“已独立掌握”。做错、使用提示不失去奖励，也不要求全答对。

- 老师调用 LearningComplete，引用本课实际作答与反馈并给出收获小结；程序验证作答归属、引用存在、对应评估/本地核对有效，以及没有依赖尚未确认的写入。程序核实事实边界，不用题数或分数另造教学判断。
- 无真实尝试、只有闲聊/播放/跳过，或引用别课作答，不能通过结课校验；反复重提旧作答不产生新完成资格。老师的普通文字、用户的一句“做完了”均不能代替工具与保存确认。
- 达到目标后及时收课，不因用户继续提问而拖延奖励；结课不强制跳走或关闭课堂。追问、复核不重新打开完成资格、不重复发币；新一课由用户明确开始。
- 中途退出保留进度，不自动结课、不罚币；明确放弃按删除规则处理。坏题或能力不可用时明确替换练习，保留已提交事实，不记成用户错误，也不暗中改变已展示奖励。
- Completion 随相关学习成果保存成功后，当前归属聊天可写且钱包已开就顺接一次结算，无需用户再点「完成/领奖」。保存失败保留已确认进度；发币失败不撤销完成，后续只重试领取。

### 9.3 三段确认，不新建跨库事务

```text
用户文件：保存 Completion + 固定奖励意图
    ↓ 同一归属 osId、当前可写才结算
聊天账本：以 learning:unit:<unitId> 幂等入账
    ↓ 确认后
用户文件：补保存到账回执；余额仍由账本提供
```

- 奖励意图随 Completion 保存 originOsId、金额、固定 title/note；归属与金额取自已发布 Unit，不从结课模型回复取值。kind=`learning_reward`、所属账户与 `learning:unit:<unitId>` 是稳定账本协议常量，不随 UI 文案或定价变化。重试从原意图恢复完整输入，不能因改名/新版本文案/当前币额常量变化而冲突。
- actionId/idempotencyKey 来自 unitId；sourceDomain 为 `learning`，sourceId 为 unitId。学习通过自有老师偏好分区的事务使用 `ECONOMY_TRANSACTION_CAPABILITY`，本次不必改老师值，不另存 chat 内完成清单。
- 结算前强读用户文件中的确认资格，检查当前 sidecar osId 与 originOsId；事务 commitGuard 再查当前身份、激活/资格。新分支 osId 不同，无权重新领取父线资格。
- 钱包已开时，完成保存后自动顺接一次结算；未开时仍保存完成事实，显示「开通钱包并领取」，用户点击后使用现有 ensureOpen。开户赠礼和学习奖励分开显示，不把 100 币赠礼冒充学得奖励。
- 学习未保存不发币；账本失败只重试发币；账本未确认走 Kernel 核实，不再提交教学评估。UI 不在回复到达、动画结束或点开成果页时先加币。
- 币已到账而回执写用户文件失败，显示需要核实回执。下一次查原账本的同 key 完整输入，补同一回执；不再次发奖、不重学。已确认回执用于跨卡展示历史结果，不是余额来源。
- 关窗/切卡后已发出的写入不承诺撤销；未发出的不继续。回到原 osId 才可补领。原聊天删除后不转移奖励、不删除学习成果；清空 Learning 前明确放弃未领资格，已发出的记账先核实再清理。

无需长期保存“正在奖励/重试中”字段或后台队列。可恢复的依据就是完成事实、固定意图、可选到账回执及现有账本；空文件不触发历史补发。原账本随故事复制的既有余额按 Economy 规则保留，不声称这些继承资金是新的学习奖励。

## 10. 声音：先把已有 TTS 接完整

### 10.1 所属播放与参数

Learning Host 持有本课 TtsPlayer 实例和取消控制；Shell 只发播放/暂停/定位等动作与接收状态，不读取鉴权配置。不能直接使用 `window.xiaobaixTts.player` 清空主聊天队列。

TTS 所有者提供窄接缝：不含 Key 的可用音色/能力读取；外部合成可传本次音色、语言提示和合成语速；完整下载传 AbortSignal；请求参数进入既有缓存键。保持旧调用省略参数时的原行为，不为学英语改全局语言/默认声线。

主队列、即时语音、课堂播放器作为现有三个实际消费者，补同一个运行内的语音播放所有权。新的明确播放暂停/停止旧所属播放，主队列不丢；旧 run 的迟到回调不释放新 owner。学习结束不擅自恢复曾暂停的主聊天声音。自动朗读在他方拥有播放权时不得抢回；背景音乐不归此协调。

播放条时长/进度来自实际媒体 metadata。每句示范直接合成保存教材的原句，不再调用 LLM 改写；合成材料明确标记 TTS，不冒充新闻原音。没有真实对齐信息就无逐词高亮/假时间戳。

### 10.2 听力题的版本与失败

- 课件确定音色和文本，播放中修改音色/材料需要另开明确尝试依据，不原地换掉已提交原答对应版本。
- TTS Blob 缓存命中可重听，缓存失效说明需要重合成；保留文本/音色依据，不承诺字节完全复原的音频法证记录。首版没有依赖某一次波形细节的发音评分。
- 合成失败保留原题/原答，重试只合成；慢放、暂停、已有音频重听不再请求模型/TTS。自动播放被拒显示可点击入口，不循环请求。
- 停止、切题、换老师/语言、切聊天、离开 APP、关闭 OS 都使所属合成/播放失效并释放资源；缓存返回后也重新检查 guard，旧声音不得突然响起。
- TTS 未开启时，语音入口明确提示「使用语音前，请先开启 TTS 模块」。点击朗读或开始听力练习时就地引导开启，不把模块关闭报成合成/API 失败，不自动替用户开启；普通打开、阅读不反复弹通知。阅读/文字学习仍完整可用，也可明确改做文字训练；看过替代文稿后记录帮助，不仍标为独立听懂。

### 10.3 录音、转写、音频反馈的后续接入门槛

这部分不在首版伪装成完成，也不改变前述资产边界。将来增加的是 Attempt 的音频载体与媒体资源，不新建语音专用课程/进度库。

1. 浏览器采集由 Host 自有模块实现，先验证安全上下文、权限、支持 MIME、时长限制和设备释放；不因为 iframe 有剪贴板 allow 就加一个假麦克风按钮。
2. 预听前录音只在内存，停止立即释放轨道；用户明确提交才上传。开始录音先停止所属播放，失败/重录/取消/离开都释放对象 URL 与设备。
3. 提交音频资源与作答记录分两次确认：文件已存在且内容摘要匹配后才保存引用；同 attemptId 重试不重复上传。附件 manifest 与引用、删除/孤儿清理的稳定方案先验证再允许持久录音，不往学习 JSON 塞 Base64。
4. 当前没有统一音频输入/转写能力，不默认给所有 Provider 发音频。选定具体已配置服务、验证协议与用户知情后再启用；只有录音可用时明确是本地跟读自查。
5. 转写只证明取得了文字；机器结果和用户纠正分开。文字评价不能伪造发音/流利度评分。需要音频反馈必须实测服务支持及可评价维度，不因 HTTP 200 就给百分制口语分。
6. 识别失败重试本次声音，不重学、不重录；不支持时可删除待提交音频或改用文字，下一次普通教学不会反复携带坏附件。删除历史录音保留可读题/文字，依赖音频的结论标明无法再复核。

在没有真实录音/识别服务验收前，交付只标“文本学习 + TTS 听力/示范已接入”，不得写“四技能已全部验收”。新增外部服务/配置面须另报具体接法，不自动购买服务或读取用户密钥试跑。

## 11. UI 与 Host 交互

### 11.1 书桌和课堂的气质

桌面名称「语伴」，本地图标使用书页与批注意象，属于 OS 图标家族。应用延续 OS 字体，浅色纸面/墨色、青绿小面积强调，深色炭灰/柔白；与世界新闻的朱红刊物区别。角色是授课者，不是浮动吉祥物；不铺题库仪表盘、全屏同款圆角卡片或聊天室换皮。

| 页面 | 内容与主动作 |
| --- | --- |
| 初次认识 | 老师选择、语言、自评与目标分步呈现；本地选择先可操作，用户确认“让老师准备”才请求模型 |
| 书桌 | 当前老师/语言/目标、一句学习方向、继续或开始主按钮；“今天少练一点”、学习记录为次级。偏好/音色/数据管理进菜单 |
| 课堂 | 材料与当前题是主体；来源、目标、完成奖励清楚。宽布局材料/辅导可并列，窄屏单列，问老师面板可收回；老师结课后仍可追问，不强制跳页 |
| 本次收获 | 老师已保存的结课小结、具体卡点、可复习内容和实际到账状态；可主动展开，不是领奖前必经页；未到账显示领取/核实，不用一排无依据分数 |
| 学习记录 | 待加强/到期/独立使用视图；打开看题、原答、解释、出处，删除/复核/再练均有明确作用域 |

文章正文纯文本按段落排版；批注指向原句。错误提示用文字/图标，不只红绿；长解释按需展开。页面返回恢复滚动/选题/输入（运行内），完整重开恢复确认单元，不声称未提交草稿已经保存。

### 11.2 可观察的动作契约

UI 通过 `learning/*` 桥接路由：读状态、选语言/老师、开始/继续、提交尝试、提问/提示、复核、暂离/放弃、重试收课、领取/核实、播放控制、删除/导出。结课由老师工具发起，没有 UI 直接标记完成的入口。Host 决定持久事实与运行 guard，不相信 iframe 传来的金额、正确与否或“已听懂”。

同一次操作的桥接 requestId 只用于回包；持久 unitId/attemptId/completion ID 才用于重复请求去重。每个回包区分确认数据与动作状态，不能 ACK 就清空输入或展示新水平。

打开、返回、换视图、选中、标记、看既有解释/记录不请求教学模型或联网服务。开始/新练习/问老师/提示/开放题评估/复核，以及提交末题后顺接的老师收课或用户重试收课可请求；该收课请求在作答提交的教学流程内告知。本地客观判题与媒体请求分别计，不用一个旋转圈掩盖所有阶段。

### 11.3 失败和取消

| 出错处 | 保留什么 | 用户入口 |
| --- | --- | --- |
| 无 Key / 无模型 / TTS 关闭 | 档案、旧课、原答仍可读 | 相应设置或选择可用训练，不整 APP 白屏 |
| 搜索/提取失败 | 当前目标与旧教材 | 重试取材/换来源/明确用自编，不自动换成假原文 |
| 用户原答保存失败 | 输入仍在；不开始评估 | 保存/核实，不让用户重打 |
| 评估失败 | 已保存的同 attemptId 原答 | 重试评估，不重搜/重传 |
| 评估保存未确认 | 旧已确认学习项，候选仅在内存 | 核实保存，不再生成一版 |
| 老师收课失败/保存未确认 | 已确认作答与反馈 | 请求失败只重试收课；保存未确认只核实，不重做题或预先发币 |
| 奖励失败/未确认 | 学习完成事实 | 领取/核实账本，阅读不重复发奖 |
| 播放失败 | 材料、题目、原答 | 本题播放重试，不写错题 |

错误显示在对应动作旁，保留安全 Provider 分类；不原样显示响应体、Token、HTML 或工程堆栈。再次进入只展示当前问题，不重复 toast、不自动请求同一失败动作。

切聊天/语言/老师、离开 APP、关闭 OS 使尚未提交教学运行失效，取消所属网络/声音；同一 APP 内翻材料或看学习记录不取消已提交评估。已发出的保存先核实实际结果；不能因 UI 离开就声称撤销了服务器写入。主剧情在同一聊天继续，不自动发起新课或中断公共教材的评估；下次问老师才取新背景。

教学写入和删除互斥；保存/记账待核实时先核实再清空。操作取消后可重新操作，但旧回调无权改变新语言、课件或老师。无聊天时仍遵守 OS 总入口规则，不在本轮为语伴另开欢迎页入口。

## 12. 分五步施工，逐关交付

### 第一步：接缝探针与仓库

**当前：底座与独立接缝验证已落地，未接生产入口。**

### 13.4 第四批当前边界

- TTS 自己持有唯一播放所有者，`createPlayer()` 与 `acquirePlayback()` 通过 Host facade 提供，避免 raw TTS 与 OS bundle 各自产生一份互斥状态。手动播放暂停上一所属声音，自动队列不抢占、不丢队列；停止课堂不自动恢复主聊天。
- TTS 只读音色信息不含 Key；请求级 `speaker`、`language`、`speed` 不改全局设置。完整下载透传取消并释放 reader；关闭模块同时取消外部合成和所属播放，过期下载/缓存不能出声。
- `learning/host/media-adapter.ts` 只处理 Host 已确定的朗读文本、播放控制和可展示状态，不调用教学 Agent、不更改学习证据。未开启模块返回「使用语音前，请先开启 TTS 模块」；普通查询不发通知，合成失败不泄露原始供应商报文。
- 播放被浏览器阻止后保留已有音频，继续/重听/慢放/定位不重新合成。替换题目、身份失效、其他声音抢占或清理后，不接受旧回调。播放状态不包含隐藏文稿。

第四批后续已完成正式接入：

- `host/runtime.ts` 只由明确动作进入老师/媒体服务；读取、切页、重进不生成。运行时身份与 sidecar 身份分别使用，停止/离开后的迟到回复不能继续教学。未确认的用户文件由 Host 会话级 repository 保留，不因关窗丢失。
- UI 为「书桌与批注」，沿用 OS 字体、纸墨与克制青绿。书桌/认识目标、材料与六类作答、老师批注、本课笔记、学习记录和收获分工明确。选段有鼠标精确选区与触屏/键盘整段按钮；提示/答案/文稿确认保存后才展示。资料在 Host 过滤，隐藏文稿及答案键不下发 iframe。
- 声音偏好属于语言档案；听力材料各片段首次实际开始播放后固定音色/语言/语速，与听取记录一起保存，不把同题其他材料强制换成这个音色。此前合成失败或播放被阻止不会保存空的听取记录，用户可换音色重试原题。长文本按稳定原文边界分片（每片最多 1,000 码点），时长只表示当前音频片段。只有实际播放事件增加片段计数，慢放/重听随原答保存；阻止播放和合成失败不算听过。高频播放进度只推送媒体状态，不反复投影整份用户档案。
- 听取记录被明确拒绝或读取失败时，暂停声音，将尚未保存的真实播放事件保留在当前课堂内存；下一次普通操作先重试这次保存，成功前不提交答案或调用老师。清理操作（删除笔记/学习项/作答、放弃本课、删除语言、清空）只等待正在进行的保存结束，不强制重试，从而能在文件满时腾出空间；清理失败不丢弃排队事实，成功后仍有效的事件继续保存，所属内容已删除的事件退场。结果未确认时仍先由用户文件仓库核实，清理也不能越过该边界；不持久化播放任务或重试队列。
- 听取记录保留播放来源题目，片段键对应真实材料；作答按引用材料的「片段＋音色/语言/合成语速」保存次数和慢放依据，共用材料不要求逐题重听。组合题保留各材料的不同音色；同片段若有多个音色也分别记录，重听次数仍按片段的总播放次数计算。快照归作答所有，进入代表证据后随证据保留、随作答/证据删除，不依赖当前课件继续存在。新播放记录按片段保存，不让另一材料的慢放污染当前题；已有作答保持提交时的快照。冲突采用后，原课程、题目或原文片段已失效的排队事件直接退场，不阻塞读取和备课；仍有效的保存故障保留显式重试。
- 声音设置同时跟随当前语言与已保存偏好。语言切换即使两边都没有偏好，也重置为新语言及默认音色/语速；不把上一语言的未保存输入带入新档案。
- 本次回归覆盖冲突采用后的课程删除/替换、题目删除、原文变化和资料范围变化；共用材料跨题听取、重听、慢放及提交快照；有效保存失败仍能恢复。正式 Vue 界面在隔离课堂验证英日无偏好切换与保存归属；未调用真实模型或语音供应商。
- 后续回归以真实接近 8 MiB 的合法文件验证容量不足→清理失败/成功→重试听取→清空→重开；覆盖未确认写入下所有清理入口仍受保护，以及组合题多音色、同片段多音色、跨课程保留的代表证据读回和非法片段拒绝。
- `unit.notes` 是用户明确保留的当前课批注，最多 12 条，每条 4,000 码点，可带严格核对原文的 UTF-16 选区和题目锚点。它随本课重开保留，逐条可删，换课/放弃课件释放；不是历史师生聊天日志。换课确认明确提醒先导出需要保留的本课笔记。
- 完成保存后自动尝试一次所属聊天结算；生产短练/常规/深练使用 20/40/60。未开钱包不自动开户；回执未确认不重复发币，核实/补领只操作原资格和账本。清空学习数据保留已到账流水。
- `module.ts`、生产组合、两份 catalog 和 Shell 懒加载已成套接入；语伴不注册剧情维护或主剧情注入。

新增 `learning-classroom.test.js` 使用正式控制器、工具、用户仓库和 Kernel/Economy，固定 Provider 响应覆盖提交→结课→自动到账、未确认完成、账本/回执断点、重复补领、跨故事投影、取消后迟到结果、文稿曝光/笔记、真实播放事件与听力依据。它验证业务契约，不代表真实模型教学质量。

### 13.5 Review 修复边界

- 作答区分同题反馈后的再练和首次独立表现，不回改先前条件；反馈事实随代表证据读回，移除原先的错误作答或换课不把再练变回独立成功。其他题的反馈与尚未评估的原答不算已得到反馈。
- 备课文字回复带所属动作，未生成课件也在书桌的备课入口展示，不依赖自动进入课堂；旧课仍可读，不保存空课程。
- 六类输入草稿由当前课堂按题持有，切题、返回、收起再练和保存未确认时保留。确认提交后清空该题草稿，换课／切语言／卸载课堂释放；草稿不写学习文件。
- 提示可用性与提示正文分开投影；没有内容时不显示入口，直接调用空提示揭示也不改学习记录。
- 回归采用最低必要层：业务通过正式工具／仓库／课堂与媒体边界测试，交互通过隔离浏览器的真实 Vue 界面。OS 640 项与 TTS 27 项通过；真实宿主课堂、真实模型教学和实际音频效果仍待验收。
- 本轮浏览器验证六类草稿、未确认保存→核实→再练、换课清理，以及有／无旧课的备课留言；320/390/960px 深浅主题与 320px 文字放大 150% 无横向溢出。Vue/TS、OS lint、变更测试 lint、imports、三路构建与 tracked/untracked diff 检查通过，dist 成套更新。

## 14. 退出与清理

删除某语言/全部学习数据是用户明确动作，先处理在途和未确认保存，再原子写剩余内容或删除整份自有用户文件并确认；删除失败保持可重试状态，不宣称数据已清空。录音能力上线后同步按资源 manifest 清理独占附件，不能删公共图库或 TTS 共享缓存。

卸载功能时取消教学与声音，撤销 `learning` module/capabilities 声明、两份 catalog、Shell 懒加载、组合项和图标；删自有目录/用户文件/老师偏好分区。共享 Tavily 设置、已知人物读取、TTS 公共接缝仍有消费者就保留；Economy 既有流水与主聊天均保留。老师偏好分区只是选择，清它不影响人物和联系人的真实数据。

文档长期保留职责与稳定契约；实现后回填实际文件和验证结果，不把这里扩成每个文件的清单或已完成任务日志。
