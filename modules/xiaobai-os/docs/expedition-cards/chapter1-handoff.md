# 守住的规矩
- docs/expedition-cards/ 下的 md 是运行时提示词（narrative/canon.ts 在运行时读取）。改了 md 就是改了线上提示词：提示词必须和对应步骤的代码一起换，不能提前。
- 分段和敌人卡只给记忆、关系、秘密的影子、亲密、处境。不要在代码或提示词里补写人物该说什么、该做什么、什么时候拒绝。
- 不要往分段、人物卡、提示词里加对话范例。
- 玩家不写名字和性别，不用 {{user}}。
- 主要人物数量、嘴遁敌人数量不写死，靠配置加。
- 每一步新增的状态，这一步就要能存档、读档、恢复，且同一条回复只结算一次。第 5 步是存档总验收。
- 兼容酒馆 1.14 和 1.18。
- 文档只留现行契约，不保留提示词草稿副本；设计文档通过引用本章规则保持一致。
- 全程不聊天也必须能一路打通第一章。

# 第 1 步：好感
做什么:
- 每个主要人物一份好感，0~100，初始 0；同时存"到过的最高段"和"已交出的秘密"。
- 回复 JSON 多一个可选字段 affection: "up" | "down"。幅度程序随机 2~4（做成配置），夹在 0~100。省略、解析不到或值不合法都当作不变。
- stage 的取法（plan 第四节）：
  - 称呼、关系、秘密的影子、亲密：当前段。
  - 记忆：0~20 起累计到到过的最高段，好感下降不收回。
  - 秘密：当前段写了才放；交出后作为"已经告诉玩家的秘密"一直放，不收回。
- "交出秘密"行动：当前段写了秘密、好感 ≥81、且还没交出过时才出现。提交后记事实（老白→八斤的料 / 三娘→常有年的料），旅途加一条。扣子、阿念第一章没有。
- 交谈界面并排两个圈，样式照 AdministratorContext.vue：
  - 好感圈：圆心爱心 SVG，环按 0~100 填充；点开浮层显示数值和当前称呼。数值变化时有一下轻提示，看得出加还是减。
  - 上下文圈：和管理员 APP 同款，显示占用和离自动摘要多远，点开看各部分占用。
- system-prompt.md 中的关系、秘密和回复字段必须与本步代码一致；地图规则与第 2 步配套。
- README.md、expedition-game-target-design.md、expedition-campaign-design.md 的关系设计引用 plan 第四节，不另维护一套数值规则。
做完的样子:
- 和老白聊几句，好感圈会动，点开看得到"过路的"。
- 好感低时问老白正门的细节，他不谈，也不编。
- 把好感调到 81 以上（仅用于这里的功能检查），出现"交出秘密"；他讲出八斤的事，旅途里记下一条。
- 交出后把好感调低：称呼、关系回到低段；记忆不少；他仍知道自己说过；料还在。
- 保存失败后重试、读档、恢复：好感不重复加减，交出秘密不重复出现。

# 第 2 步：地图与移动
做什么:
- 人物位置（场景、坐标、是否跟随）进存档，作为唯一来源。画面、交互距离、提示词里的场景、map 里的"你在不在"、事件见证都从它派生。
- 提示词里放 map：第一章每个地方的名字、这个人在不在、玩家在不在、现在能不能去、安不安全。
- 三种移动行动（plan 第五节）：
  - 跟随：跨场景跟着玩家，可以进战区；在战区里不攻击、不被当目标。
  - 同行到某地：人物自己走过去等着；只列能去且安全的地方，战区不列。
  - 留下：停在原地。留在营地外的，玩家离开那个场景后回营地默认位置。
- 扣子、阿念在 captives_arrived 之前没有移动行动。
- 战败重试、返回营地：跟随中的人物和玩家一起走。读档按存档位置出现。
- 营地约会点：老白外门门楼，扣子管架高处，三娘诊棚后，阿念登记棚。
- system-prompt.md 的"地图与去哪"与本步代码配套，不提前承诺未实现的地图功能。
- expedition-campaign-design.md 遵循同一移动边界：人物只能通过游戏提供的移动行动移动，由游戏校验执行。
做完的样子:
- 让老白陪你去门楼，他自己走过去等你，回复里不写"到了"。
- 要他去哨站深处，他说得出为什么现在不行。
- 带三娘跟随进战区，她跟着跑，敌人不打她；战败重试，她和你一起回起点。
- 让老白留在岔口，你回营，他也回到门楼。
- 救人前问扣子能不能跟你走，没有移动行动可提交。
- 上面每种情况读档后，画面、交互、提示词、map 四处一致。

# 第 3 步：嘴遁遭遇机制，先接八斤（正门）
做什么:
- 做成一套通用机制，每个敌人一份配置：敌人卡、开场、料事实、放行后记哪条事实、旅途文案、放行时的让路表现。
- 正门敌人外面加一圈"照面区"，比警戒区大。玩家进来，八斤转向玩家、往前一步，出现"交谈"提示。按交互键打开交谈面板；直接走进警戒区照常开打。战斗开始后不能再交谈。
- 交谈面板和主要人物同一套，只显示上下文圈，不显示好感圈。面板打开时游戏暂停。
- 提示词：enemy-system-prompt.md + enemy-bajin.md + 世界资料 + 开场 + 玩家身边跟着谁 + 八斤自己的交谈记录。
- 结果：
  - 还没提交行动：玩家随时能关面板走开，他回原位；再来时记得上次的话。
  - 放行：只有玩家持有"老白→八斤的料"时才出现在 actions 里。面板留着他最后一句，玩家自己关掉后，盾卫让开，记 patrol_cleared，旅途加"八斤侧过盾，让开了。"
  - 动手：面板留着他最后一句，只剩"迎战"按钮，按下开打。提交了就不能退走。
- 打赢或放行后，八斤退到一边站着，照面区还在，能说话，没有行动。
- 敌人交谈记录、遭遇结果进存档。
做完的样子:
- 没有料：怎么聊都没有放行，他把你当货。
- 有料，说对了：读完最后一句、关掉面板，盾卫让开，不打就过正门。
- 有料，说蠢了：他动手，按"迎战"开打。
- 谈到一半走开，回来他记得；读档后也记得。

# 第 4 步：常有年（烽火台）
做什么:
- 不新写一套实现：给第 3 步的机制加一份常有年的配置。敌人卡 enemy-changyounian.md，料是"三娘→常有年的料"。
- 放行记 alarm_silenced：烽火不点，援兵不来。牢门惊动守军之后再来谈也一样。让路表现是火盆边的人退开、火绳收起。旅途加"常有年眯着眼看了你一会儿，叫人把火绳收了。"
做完的样子: 和第 3 步一样，换成三娘和烽火台。

# 第 5 步：物资对账；存档总验收
做什么:
- 诊棚东侧货车核对物资时，玩家看到两样东西：
  - 放还单："冷却管件十二副，库中仅此，余者冻裂报损。"
  - 管件箱里夹着的出库签："本箱原装二十四副，出十二，存十二，完好。"
  没有任何人评论，三娘收尾也不提。
- 记一条"看过出库签"进存档，不进任何提示词，不影响本章任何判断。
- 存档总验收：好感、到过的最高段、交出的秘密、两个嘴遁结果、敌人交谈记录、人物位置、开关状态、看过出库签，在保存失败重试、读档、后台恢复、章末之后都正确，章末不清。
做完的样子: 核对时看得到两张对不上的单子；plan 第十一节"状态正确"全部通过。

# 第 6 步：文案

做完的样子: 界面上找不到"击退""突破""解除封锁"；同一个营地互动连做三次，三段不一样。
