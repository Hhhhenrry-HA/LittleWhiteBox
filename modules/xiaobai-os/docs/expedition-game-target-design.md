# 余烬远征

小白主角的俯视角动作肉鸽。免费入场，无付费复活、不下注、不调用模型，不读主聊天内容。移动中自动攻击最近敌人，玩家决定走位、闪避与技能时机。键盘和触屏使用同一组离散方向与动作。

## 产品循环

三片区域：风息庭院、月潮回廊、日冕王城。每片五个路线节点，以首领收尾。中途在战斗、精英、篝火、祭坛、商店之间作有代价的选择；路线与遗物在出现时确定，刷新不重抽。碎晶只在本局购买遗物，不与钱包兑换。

长剑以近身横斩和回旋格挡为核心，弓依赖射线与距离，杖依赖范围伤害。普攻、主动技能、位移和敌人判定均由纯战斗规则拥有。盾卫正面减伤，祭司为附近普通敌人减伤，射手和冲锋敌人有可见蓄力。首领通过范围预警、放射弹幕、连续冲击和阶段增援改变局面。

遗物提供雷场连锁、灼烧传播、冰缓碎冰、反击反射、远程贯穿、技能循环等可交叉联动；每局从全目录随机抽取十二种组成遗物池，不保证凑齐指定组合。装备槽有限，满槽后明确替换或放弃。伤害提高类遗物附带代价。具体参数唯一位于 `expedition/content.ts`，名称、效果说明和反馈唯一位于 `copy.ts`。

长期成长增加选择而非永久攻击力：首领首胜开放武器和披风，胜利开放迅疾、孤旅、重围三条可组合誓约。遗物发现、武器通关和誓约通关永久保留；本局构筑、生命、碎晶不带入下一局。最近战绩有固定上限。有限内容不宣称无限耐玩。

## 画面与操作

战场采用斜俯视微缩遗迹：铺石、台阶、拱门、庭院植被与远处城廓共同形成空间，而不是在纯色棋盘上摆角色。庭院、月潮和日冕分别使用风向纹章、月轮与日冕地面图案及各自的石材、植被和建筑顶部。小白引用统一母版并等比放大，武器和披风独立附着；首领的重甲锤盾、浮游月冠与王冠巨剑有不同轮廓和蓄力演出。

镜头朝向唯一位于 `visuals.ts`，键盘和摇杆在输入入口转换为世界方向，再进入原有重放协议。屏幕上的上、下、左、右与操作方向一致；存档里的历史输入不重新解释。手机战场采用较近取景，屏幕外敌人以边缘指示显示。危险区域、投射物、技能冷却、受击数字和装备状态直接由战斗状态投影，不维护第二份生命或计时规则。减少动态效果时停用晃动、奔跑起伏和装饰运动，保留危险预警与操作反馈。

场景生命周期由 `scene.ts` 拥有；`scene-kit.ts` 管共享几何与材质，`scene-world.ts` 管静态建筑，`scene-actors.ts` 管敌人及装备，`scene-effects.ts` 管复用的战斗特效。静态建筑按材质合批，角色与特效不每帧创建几何；离开后统一释放 GPU 资源。暂停的战斗、静止的路线/奖励页不重复渲染。动作音效是本地 Web Audio 的短促分层声音，默认关闭，不下载素材或调用外部服务。

营地让玩家看小白、选装备和直接启程；路线页呈现进度与下一位首领，奖励页呈现可比较的遗物。`icon-art.ts` 拥有原创矢量图形，奖励、行囊、收藏与战斗装备栏引用同一份图形。游戏保持自己的深青与浅金界面语言，宿主深浅主题不改变战场警示颜色。小屏重新排布奖励与操作区，不把桌面卡片压成难读的小字。

## 所有权和执行边界

`apps/game/expedition/` 自带规则、内容、命令、存储、资金、Host、客户端与画面。仅从 Game module、production runtime 和 room catalog 注册。共享小白形象与动作属于 `brand/mascot`；场景拥有武器、披风和战场，不复制一套小白母版。只使用已有 Vue 和 Three.js。

固定步长的战斗只接受方向、闪避和技能输入；不接受客户端生命、伤害、随机或胜负。浏览器运行同一规则即时呈现，按固定间隔发送压缩输入，宿主从上次确认状态重放，随后提交检查点。每次输入有总帧数上限，重放不读墙钟；页面丢帧不会加速。奖励界面必须等最后输入保存确认后开放。宿主重放用于保证协议和资金一致性，不宣称能防止本地用户自动化输入或修改自己的存档。

进行中的远征、已展示的路线和遗物、战斗检查点是跨重启恢复所必需的持久事实，归用户级 `expedition` 分区所有。已确认奖励收据与钱包在同一个事务里提交，重复 actionId 不重放或重复发奖。首次首领、首次总通关、每种武器和每条誓约首次通关奖励有明确上限；常规重玩不重复发币。

首次成就收据是武器、披风和誓约完成情况的唯一事实来源。展示层派生解锁列表与本局已获金额，不另存重复的已解锁字段或奖励合计。总胜场保留独立计数，因为有限战绩册不能还原终身总数；遗物发现不依赖有限战绩册。

临时态只有未确认输入、按键、画面、音效、暂停、面板和镜头。隐藏、离开、失焦、故事生成时暂停；正常暂停提交剩余输入。意外关闭最多回到最近一次已确认检查点，不承诺保存尚未确认的帧。上传失败冻结战斗，核实原候选后才能继续；不重复生成已展示内容。声音默认关闭，只在本次打开期间记忆选择。

## 生命周期与兼容

不兼容不存在的旧远征格式。现行用户文件、Economy、Host/SillyTavern 和浏览器 WebGL/Web Audio 是外部边界；画面或声音出错明确提示，不静默换成文字游戏。删除前确认远征进度与收藏丢弃/导出策略；随后删除 feature 目录、三个注册并清理分区。已发生的钱包流水保留，不倒扣。聊天清理不删除用户级解锁。

## 验证

规则测试保护输入重放、伤害、闪避、格挡、联动、阶段与路线选择；事务集成测试保护费用为零、奖励幂等、失败与未知提交恢复、跨重启恢复、非法客户端输入拒绝。现有 OS 类型、lint、测试和构建应通过。浏览器检查真实入口、键盘、触屏、小屏、深浅主题、暂停/返回、奖励选择和恢复；策略模拟用于寻找数值问题，不冒充真人乐趣测评。
